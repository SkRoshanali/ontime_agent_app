# Admin & Agent App Spec

**Project**: Admin and delivery-agent web application for a shared grocery ordering system  
**Database**: Shared Neon Postgres (Project 1's schema, no modifications)  
**Status**: Requirements → Design → Tasks → Implementation

---

## Phase Summary

| Phase | Focus | Deliverable |
|-------|-------|-------------|
| **P1** | Scaffold + config | Next.js project, env, db connection, type setup |
| **P2** | DB + auth | Drizzle ORM queries, login/logout, JWT sessions |
| **P3** | Agent dashboard + batch claiming | Agent UI, atomic batch claim endpoint |
| **P4** | Pick/pack lists + batch lifecycle | Pick/pack screens, order status updates, delivery |
| **P5** | Admin dashboard + order management | Admin home, order list, filters, manual status changes |
| **P6** | Manual batch release + agent mgmt | Release batch endpoint, phone verification, agent creation |
| **P7** | Print CSS | Pick/pack list print styles |
| **P8** | Final verification + README | End-to-end flow, docs, tsc/lint/vitest |
